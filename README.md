# kth_to_Default_Basket_CDS_Pricing
CQF Final Project (92%). Prices 1st- to 5th-to-default basket CDS on five European names under Gaussian and Student-t copulas: hazard curves bootstrapped from assumed CDS spreads, t-copula degrees of freedom fitted by MLE, scrambled Sobol simulation, exact protection-leg validation, and an IRRBB vs CSRBB split under BCBS 368 shocks.
